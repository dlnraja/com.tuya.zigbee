# Bare AggregateError: one identical retry (P3341)

A bare Athom AggregateError (stateMeta exactly "AggregateError", empty message: the Node net multi-address connect failure) gets exactly ONE identical retry: bumped version, P3311 first backoff (>= 300 s + jitter), only when Athom already holds a final processing_failed build for that version (no duplicate). It keeps class real: push runs stay blocked by the breaker, only retry 1 of the chain is exempt, and a second failure trips the breaker and notifies as before. AggregateError with a message and every other real error get no retry. Code: `.github/scripts/athom-publish-policy.js` (shared, byte-identical on the 3 branches). SSOT: `config/architecture/publish-ssot.json` key `bareAggregateRetry`. Full text: `docs/knowledge/P3036_ATHOM_PUBLISH_POLICY.md`.
