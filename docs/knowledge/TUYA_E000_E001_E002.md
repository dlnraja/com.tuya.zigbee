# Tuya manufacturer clusters 0xE000 / 0xE001 / 0xE002

SSOT from Google `0xE002 tuya` sweep (P2267) + Z2M / ZHA / zigpy #823 / Zigbee-Peek-and-Poke / HA community.

## Taxonomy (Z2M canonical)

| Cluster | ID | Z2M name | Role |
|---------|-----|----------|------|
| DP tunnel | `0xEF00` | `manuSpecificTuya` | MCU datapoints (not ZCL attrs) |
| Options / buttons | `0xE000` | `manuSpecificTuya4` | Timing / button frames |
| Switch / power-on | `0xE001` | `manuSpecificTuya3` | `powerOnBehavior` 0xD010, `switchMode` 0xD020, `externalSwitchType` 0xD030 |
| Alarms / OEM radar | `0xE002` | `manuSpecificTuya2` | Climate thresholds **or** Linptech radar attrs |

Homey registers **one** Cluster class per ID → `TuyaE002Cluster` merges climate `0xD00*` + Linptech `0xE00*`.

## 0xE002 climate attributes (ManuSpecificTuya2)

| Attr | ID | Type | Notes |
|------|-----|------|-------|
| alarmTemperatureMax | `0xD00A` | int16 | Whole °C (Neo) or centi on some LCD |
| alarmTemperatureMin | `0xD00B` | int16 | |
| alarmHumidityMax | **`0xD00D`** | int16 | Z2M + Abysim; upstream ZHA wrongly used `0xD00C` |
| alarmHumidityMaxLegacy | `0xD00C` | int16 | RX alias only |
| alarmHumidityMin | `0xD00E` | int16 | |
| alarmHumidity | `0xD00F` | enum8 | ValueAlarm 0=min 1=max 2=off |
| alarmTemperature | `0xD006` | enum8 | Same ValueAlarm |
| beepSilence / unknown | `0xD010` | uint8 | Write `1` to mute beeper (HA #692449) |

**E002 does not carry live temperature/humidity** — those use ZCL `0x0402` / `0x0405` (EP1 or virtual EP2 after magic `0xFFFE`).

## Runtime

- Writer: `lib/tuya/TuyaE002AlarmManager.js`
- Cluster: `lib/clusters/TuyaE002Cluster.js`
- Settings: `lcdtemphumidluxsensor` + `lcdtemphumidsensor` (silence + thresholds)
- Wake sleepy sensors (button / magic packet) before writes
