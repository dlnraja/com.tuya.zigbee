Zigbee Bastien est une app Homey Pro privee pour une seule maison. Elle pilote les appareils Zigbee Tuya en local sur la box Homey de Bastien, sans partager les slots publics Universal Tuya ou Stable.

Les apprentissages de cette maison (empreintes, DP, fiabilite) peuvent remonter vers Universal Tuya et Stable. Les apps publiques ne versent pas leurs fonctions en masse dans cette piste privee.
