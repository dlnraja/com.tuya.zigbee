# Universal Tuya ZigBee Device Integration

## ENGLISH

### 🚀 Universal Tuya ZigBee Device Integration with AI-Powered Features

A comprehensive Homey SDK3+ application for integrating Tuya ZigBee devices with advanced AI-powered features, local mode operation, and multilingual support.

#### ✨ Features
- **249+ Tuya ZigBee Drivers** - Complete device coverage
- **Local Mode Operation** - No cloud dependency required
- **AI-Powered Features** - Intelligent device detection and optimization
- **Multilingual Support** - English, French, Dutch, Tamil
- **Zigbee Cluster Referential System** - Local database for device types
- **Automated Workflows** - 92+ GitHub Actions for continuous integration
- **Real-time Dashboard** - Live metrics and device status

#### 🛠️ Installation
\\\ash
# Clone the repository
git clone https://github.com/dlnraja/com.tuya.zigbee.git

# Install dependencies
npm install

# Build the application
npm run build

# Install on Homey
npm run install
\\\

#### 📊 Dashboard
Visit our live dashboard: [https://dlnraja.github.io/com.tuya.zigbee/](https://dlnraja.github.io/com.tuya.zigbee/)

#### 🔧 Development
\\\ash
# Run in development mode
npm run run:clean

# Validate the application
npm run validate

# View logs
npm run logs
\\\
